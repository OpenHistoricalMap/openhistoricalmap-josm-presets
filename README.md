# OpenHistoricalMap JOSM Presets

JOSM presets for mapping in OpenHistoricalMap. These allow you to see `start_date` and `end_date` for features in JOSM list views:

![Relations List showing start_date/end_date](/dates-preset.png)

See [OpenHistoricalMap/JOSM][1] on the wiki for instructions on setting this up.

[1]: https://wiki.openstreetmap.org/wiki/OpenHistoricalMap/JOSM#List_Views
